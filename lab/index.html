Improve a model

Make a new version of an installed model with its own instructions, then test it against the original. Ollama reuses the original's weights, so this takes seconds and almost no disk space. It changes how the model is told to answer, not what it knows; training a model on your own code is a separate step.

Tip: open a model's failed answers in the leaderboard first. If most fail for the same reason (a loop, a method call such as .lower()), say exactly that in the instructions.
